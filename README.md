# KI-kurs for lærere

Statisk nettside som samler Kurs 1–3 i kunstig intelligens (Høgskolen i Østfold): sammendrag, bilder, videoer, kilder og søk.

Åpne `index.html` for å starte. Ingen bygging eller server er nødvendig.

- `index.html`: forside med de tre kursene
- `kurs-N.html` og `kurs-N-modul-M.html`: kurs- og modulsider
- `videoer.html`, `kilder.html`, `sok.html`
- `assets/`: stil, skript og søkeindeks
- `bilder/`: bilder fra kursene (webp)

Kursteksten tilhører Høgskolen i Østfold. Hold repoet privat med mindre du har rett til å publisere innholdet.
